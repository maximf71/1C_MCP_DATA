# Отчёт о реализации 1.2.0

Дата проверки: 2026-07-27.

## Реализовано

- отдельный STDIO MCP `mcp-1c-data`, без изменения `mcp-1c-analog`;
- официальный Go MCP SDK `v1.6.0`;
- семь read-only инструментов, включая `get_latest_documents` и
  `get_document_table_parts`;
- отдельное расширение `MCP_DataAccess` и HTTP-сервис `mcp-data`;
- метаданные с синонимами, стандартными/пользовательскими полями,
  табличными частями и основными виртуальными таблицами;
- поиск метаданных по точному имени реквизита и непрозрачная курсорная
  пагинация;
- фильтры глобального поиска по ответственному, организации, проведению и
  включительному диапазону дат;
- очищенная подробная ошибка компилятора языка запросов 1С;
- локальная read-only-политика, компиляция запроса в 1С без выполнения,
  одноразовые планы на 60 секунд;
- типизированные параметры и результаты;
- RLS-bound выполнение без привилегированного режима;
- лимиты времени, строк, размера, параллелизма, очереди и частоты;
- инструкции MCP против неподтверждённых выводов и prompt injection из данных.

## Что требует окружения пилота

Полный HTTP/RLS-набор не имитируется модульным тестом. Для закрытия приёмки
нужна публикация синтетической базы и два пользователя 1С с разным RLS.
Сценарии и критерии перечислены в `PILOT_ACCEPTANCE.md`. До их прохождения
бинарник является готовой сборкой для стенда, но не считается допущенным к
продуктивной базе.

## Контроль старого проекта

В отдельном локальном проекте `mcp-1c-analog` по окончании осталось 64 исходных файла
(исключая его `dist` и `integration`). Самый поздний timestamp —
`docs/NATURAL_LANGUAGE_DATA_AUDIT.md`, `2026-07-25 15:10:01`; после начала
реализации нового MCP файлов в старом проекте не создавалось и не изменялось.

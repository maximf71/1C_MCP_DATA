# Приёмка пилота mcp-1c-data

Поддерживаемая платформа: строго `8.3.27.2214`.

## Автоматические проверки

```powershell
.\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File '<path-to-cfe-validate.ps1>' `
  -ExtensionPath '.\extension\src' -Detailed
```

Ожидается: все Go-тесты зелёные, структурная проверка расширения — 0 ошибок,
платформенный `CheckConfig` — «Ошибок не обнаружено».

## Синтетическая база

Создать известные данные:

- номенклатура и склады;
- приход/расход с табличными частями;
- периодический регистр сведений;
- регистр накопления с остатками и оборотами;
- пользователь `ReaderAll` видит все организации;
- пользователь `ReaderRestricted` по RLS видит только организацию A.

Одни и те же MCP-сценарии запустить двумя отдельными процессами с разными
переменными окружения.

Обязательные сценарии:

1. список с `ПЕРВЫЕ` и явным лимитом;
2. агрегат за период с параметрами дат;
3. остатки на дату через виртуальную таблицу;
4. документ и его табличная часть;
5. пустой результат;
6. неоднозначный бизнес-термин — до запроса требуется уточнение;
7. данные организации B недоступны `ReaderRestricted`;
8. пакет, временная таблица, комментарий, `SELECT *` и безлимитный список
   отвергаются до 1С;
9. повторное/просроченное `validation_id` отвергается;
10. 201-я строка приводит к `truncated=true`, а не к утверждению о полноте;
11. один тяжёлый запрос выполняется, два ждут, четвёртый получает
    `QUERY_QUEUE_FULL`; отмена клиента завершает ожидание;
12. ответ более 4 MiB и запрос дольше 30 секунд завершаются контролируемой
    ошибкой без тела ответа и технической трассировки.

Агрегаты сравниваются с заранее вычисленными эталонами. Для ссылок,
перечислений, дат и `null` проверяется типизированная JSON-форма, не только
представление.

## Реальная база

Только:

- `get_configuration_info`;
- поиск и схема заранее согласованных объектов;
- заранее согласованные агрегаты без персональных строк.

Запрещено возвращать персональные записи при smoke-проверке.

## Критерий допуска

Пилот допускается, только если нет открытых P0/P1 по RLS, секретам,
неподтверждённым результатам и неконтролируемой нагрузке. Любой дефект этих
категорий получает воспроизводимый регрессионный тест до следующего запуска.

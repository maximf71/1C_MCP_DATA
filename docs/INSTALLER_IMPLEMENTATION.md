# Реализация гибридной установки 1.1.5

Комплект состоит из четырех изолированных частей:

1. WPF-мастер `installer/Install-MCP1CData.ps1`, запускаемый через `Setup.cmd`.
2. STDIO MCP `mcp-1c-data.exe` с шестью read-only инструментами, включая контролируемый глобальный поиск последних документов.
3. `mcp-1c-data-launcher.exe`, читающий профиль, расшифровывающий DPAPI CurrentUser и запускающий ядро с секретами только в среде дочернего процесса.
4. Расширение `MCP_DataAccess.cfe` с HTTP-сервисом и административной диагностикой в собственной подсистеме.

## Границы доверия

- Apache слушает только `127.0.0.1`.
- В VRD отключены web-сервисы и OData. Платформенный флаг публикации HTTP-сервисов расширений включен, а внешний доступ ограничен Apache точным путем `/hs/mcp-data`.
- VRD не содержит пользователя и пароль 1С.
- JSON-профиль не содержит секретов; файл учетных данных зашифрован DPAPI и связан дополнительной энтропией с ID профиля.
- TOML Codex содержит только путь к лаунчеру и профилю.
- CFE не обращается к ОС, файлам, паролям или внешним процессам.
- Перед первой мутацией базы обязателен успешный `/DumpIB` в DT.

## Идемпотентность

Повторная установка обновляет версионный каталог бинарников и профиль с тем же ID. Управляемый блок Codex заменяется по маркерам, поэтому не дублируется. Перед каждой записью существующего `config.toml` создается новая резервная копия. Apache предыдущего локального экземпляра останавливается перед заменой каталога.

## Автоматические проверки

- `go test ./...` и `go vet ./...`;
- Windows DPAPI round-trip и отрицательная проверка энтропии другого профиля;
- сохранение и идемпотентное обновление посторонних секций Codex;
- валидаторы формы, объекта, подсистемы, роли и CFE;
- загрузка XML-исходников, `UpdateDBCfg` и `CheckConfig` на платформе 8.3.27.2214;
- экспорт CFE, повторная загрузка именно CFE, `UpdateDBCfg` и повторный `CheckConfig`;
- `httpd -t` и `/info` smoke-test выполняются самим мастером в целевой среде.

Полная Apache/RLS-приемка требует установленного `wsap24.dll` точной версии и двух пользователей синтетической базы с различающимися RLS. До этого мастер корректно блокирует установку до изменений.

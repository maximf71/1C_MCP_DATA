# История изменений

## 1.2.0 — 2026-07-28

- фильтры ответственного, организации, проведения и диапазона дат в
  `get_latest_documents`;
- сохранение всех совпадений максимальной даты до лимита 20;
- новый read-only инструмент `get_document_table_parts`;
- поиск метаданных по наличию реквизита;
- курсорная пагинация `search_metadata`;
- подробные очищенные ошибки компиляции запросов 1С;
- установщик с необязательной DT-копией и безопасной многопрофильной
  публикацией Apache;
- расширение `MCP_DataAccess` 1.2.0.

## 1.1.5 — 2026-07-27

- устойчивое переиспользование Apache и бинарников для нескольких профилей;
- отдельные конфигурации, PID/error-файлы и резервирование портов;
- выбор создания DT-копии с отдельным предупреждением.

## 1.1.4 — 2026-07-27

- глобальный RLS-safe поиск последних документов;
- стандартные поля журналов документов;
- полный охват доступных видов с fail-closed поведением.
